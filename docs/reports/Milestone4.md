## Delivered

- Durable protected helper journal: initial/intended/observed layouts, per-mutation flushed intent, verification/failure records, exclusive writer, fail-closed restart inspection and no automatic replay.
- Virtual-only immutable region model: stable identifiers, original byte boundaries, all other partitions protected, child-region tracking, stale/replayed/modified confirmation refusal. This is not a physical authorization mechanism.
- Complete before/after disk layout in execution confirmation; scrollable/resizable dialogs, Cancel-focused dangerous actions, high-contrast palette support; removed a large decorative shadow.
- Non-storage crash probe and security/fault regression tests; additional real VHDX tests ready to run.
- Guarded disposable-VM installer harness and read-only journal inspection script.
- Preview app/helper/installer build, dependency inventory, CycloneDX SBOM, vulnerability audit and SHA-256 manifest generated by `scripts/build-release.ps1`.
